## Installation

Search is a local composition built from `InputGroup`, `InputGroupInput`, and
`InputGroupAddon`.

## Usage

```tsx
import {
  InputGroup,
  InputGroupAddon,
  InputGroupInput,
} from "@/components/ui/input-group";
```

```tsx
<InputGroup variant="component">
  <InputGroupAddon>
    <SearchIcon />
  </InputGroupAddon>
  <InputGroupInput placeholder="Search products" />
</InputGroup>
```

## API Reference

### Search Composition

| Primitive | Purpose |
| --- | --- |
| `InputGroup` | Owns the search surface, size, radius, variant, focus, and invalid state. |
| `InputGroupAddon` | Holds icons, keyboard hints, or inline actions. |
| `InputGroupInput` | Provides the actual input field. |
| `InputGroupButton` | Adds clear, submit, or filter actions inside the group. |

### InputGroup Props

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "component" \| "muted"` | `"default"` |
| `size` | `"default" \| "sm"` | `"default"` |
| `radius` | `"squared" \| "rounded"` | `"squared"` |
| `className` | `string` | - |
