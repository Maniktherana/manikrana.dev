## Installation

```bash
bunx shadcn@latest add select
```

## Usage

```tsx
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select";
```

```tsx
<Select defaultValue="us">
  <SelectTrigger>
    <SelectValue placeholder="Choose region" />
  </SelectTrigger>
  <SelectContent>
    <SelectGroup>
      <SelectItem value="us">United States</SelectItem>
      <SelectItem value="in">India</SelectItem>
    </SelectGroup>
  </SelectContent>
</Select>
```

## API Reference

### Select

`Select` is the Base UI select root.

| Prop           | Type     | Default |
| -------------- | -------- | ------- |
| `defaultValue` | `string` | -       |
| `value`        | `string` | -       |
| `onValueChange`| `(value: string) => void` | - |
| `disabled`     | `boolean` | -      |

### SelectTrigger

| Prop        | Type                  | Default     |
| ----------- | --------------------- | ----------- |
| `size`      | `"sm" \| "default"`   | `"default"` |
| `className` | `string`              | -           |

### SelectContent

By default, content aligns to the trigger start. Its minimum width is the trigger width, and it can grow for longer options.

| Prop                   | Type                                      | Default   |
| ---------------------- | ----------------------------------------- | --------- |
| `side`                 | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"` | `"bottom"` |
| `sideOffset`           | `number`                                  | `4`       |
| `align`                | `"start" \| "center" \| "end"`            | `"start"` |
| `alignOffset`          | `number`                                  | `0`       |
| `alignItemWithTrigger` | `boolean`                                 | `false`   |
| `className`            | `string`                                  | -         |

### SelectItem

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `value`     | `string` | -       |
| `disabled`  | `boolean`| -       |
| `className` | `string` | -       |
