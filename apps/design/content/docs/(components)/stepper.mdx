## Installation

```bash
bunx shadcn@latest add stepper
```

## Usage

```tsx
import { Stepper } from "@/components/ui/stepper";
```

```tsx
<Stepper count={5} defaultValue={1} />
```

Use `value` and `onValueChange` when another view owns the current step.

```tsx
const [step, setStep] = useState(0);

<Stepper count={5} value={step} onValueChange={setStep} />;
```
