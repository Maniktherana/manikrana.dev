## Installation

```bash
bunx shadcn@latest add input
```

## Usage

```tsx
import { Input } from "@/components/ui/input";
```

```tsx
<Input type="email" placeholder="Email" />
```

## API Reference

The `Input` component accepts all native `<input>` props plus the following styling props.

| Prop           | Type                                  | Default     |
| -------------- | ------------------------------------- | ----------- |
| `controlSize`  | `"default" \| "sm"`                   | `"default"` |
| `radius`       | `"squared" \| "rounded"`              | `"squared"` |
| `variant`      | `"default" \| "component" \| "muted"` | `"default"` |
| `type`         | `React.HTMLInputTypeAttribute`        | -           |
| `disabled`     | `boolean`                             | `false`     |
| `aria-invalid` | `boolean`                             | -           |
| `className`    | `string`                              | -           |
```
