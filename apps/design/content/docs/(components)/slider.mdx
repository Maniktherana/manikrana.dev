## Installation

```bash
bunx shadcn@latest add slider
```

## Usage

```tsx
import { Slider } from "@/components/ui/slider";
```

```tsx
const [value, setValue] = React.useState([42]);

<Slider label="Opacity" value={value} onValueChange={setValue} min={0} max={100} step={1} />;
```

The public value shape follows shadcn's slider convention: use a one-item number array for
`value`, `defaultValue`, `onValueChange`, and `onValueCommit`.
