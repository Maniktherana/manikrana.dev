## Installation

`CodeBlock` is a local composition that lives in `src/components/design`. There is no
registry command to add it; the source is owned by this project.

```tsx
// src/components/design/code.tsx
// Source-owned composition. Edit directly in this repo.
```

## Usage

```tsx
import {
  CodeBlock,
  CodeBlockBody,
  CodeBlockContent,
  CodeBlockHeader,
  CodeBlockSource,
} from "@/components/design/code";
```

For the common case, render a complete (header-less) block from a raw string with
`CodeBlockSource`:

```tsx
<CodeBlockSource code={code} language="tsx" collapsible />
```

The header is a plain slot — compose whatever primitives you want inside it:

```tsx
import { Badge } from "@/components/ui/badge";
import { CopyButton } from "@/components/ui/copy-button";

<CodeBlock>
  <CodeBlockHeader>
    <Badge variant="secondary">TSX</Badge>
    <span className="text-xs text-muted-foreground">save-button.tsx</span>
    <CopyButton value={code} className="ml-auto" />
  </CodeBlockHeader>
  <CodeBlockBody>
    <CodeBlockContent code={code} language="tsx" />
  </CodeBlockBody>
</CodeBlock>;
```

## Composition

`CodeBlock` provides the expanded-state context that `CodeBlockBody` and
`CodeBlockExpandTrigger` read from. `CodeBlockHeader` is an unstyled slot — it has no
baked-in badge, path, or copy button; you compose those from existing primitives.

```text
CodeBlock
├── CodeBlockHeader        (optional — compose Badge / text / CopyButton)
└── CodeBlockBody
    ├── CodeBlockContent
    └── CodeBlockExpandTrigger (auto, when collapsible)
```

## API Reference

### CodeBlock

The root container. Provides the surface and the expanded-state context.

| Prop              | Type                          | Default     |
| ----------------- | ----------------------------- | ----------- |
| `variant`         | `"surface" \| "bare"`         | `"surface"` |
| `defaultExpanded` | `boolean`                     | `false`     |
| `className`       | `string`                      | -           |
| `...props`        | `React.ComponentProps<"div">` | -           |

`variant="surface"` is a standalone rounded/bordered card. `variant="bare"` drops the outer
chrome for embedding inside another bordered container (e.g. under a docs preview).

### CodeBlockHeader

An unstyled header slot. Compose `Badge`, a filename `span`, `CopyButton`, etc.

| Prop        | Type                          | Default |
| ----------- | ----------------------------- | ------- |
| `className` | `string`                      | -       |
| `...props`  | `React.ComponentProps<"div">` | -       |

### CodeBlockBody

The body surface. Reads `expanded` from context, sets `data-collapsed`, and renders the fade
plus an automatic `CodeBlockExpandTrigger` when `collapsible` and collapsed.

| Prop          | Type                          | Default |
| ------------- | ----------------------------- | ------- |
| `collapsible` | `boolean`                     | `false` |
| `flush`       | `boolean`                     | `false` |
| `className`   | `string`                      | -       |
| `...props`    | `React.ComponentProps<"div">` | -       |

`flush` fills the `CodeBlock` surface edge-to-edge (no inset frame) for header-less blocks.

### CodeBlockContent

Synchronously highlights `code` with shiki. The line-number gutter is a real element
(`[data-slot=code-block-line-number]`) so it can be styled.

| Prop              | Type                          | Default |
| ----------------- | ----------------------------- | ------- |
| `code`            | `string`                      | -       |
| `language`        | `string`                      | `"tsx"` |
| `showLineNumbers` | `boolean`                     | `true`  |
| `highlighted`     | `React.ReactNode`             | -       |
| `className`       | `string`                      | -       |
| `...props`        | `React.ComponentProps<"div">` | -       |

### CodeBlockExpandTrigger

Toggles the expanded state in context. Rendered automatically by `CodeBlockBody` when
collapsible, but can be composed manually.

| Prop        | Type                             | Default |
| ----------- | -------------------------------- | ------- |
| `className` | `string`                         | -       |
| `...props`  | `React.ComponentProps<"button">` | -       |

### CodeBlockSource

Convenience wrapper that renders a complete header-less block (with a floating `CopyButton`)
from a raw source string.

| Prop              | Type              | Default |
| ----------------- | ----------------- | ------- |
| `code`            | `string`          | -       |
| `language`        | `string`          | `"tsx"` |
| `collapsible`     | `boolean`         | `false` |
| `showLineNumbers` | `boolean`         | `true`  |
| `highlighted`     | `React.ReactNode` | -       |
| `defaultExpanded` | `boolean`         | `false` |

### Code

Inline code for use within prose.

| Prop         | Type                           | Default  |
| ------------ | ------------------------------ | -------- |
| `background` | `"base" \| "muted"`            | `"base"` |
| `className`  | `string`                       | -        |
| `...props`   | `React.ComponentProps<"code">` | -        |
