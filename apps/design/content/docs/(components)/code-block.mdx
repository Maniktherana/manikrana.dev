## Installation

`CodeBlock` is a local composition that lives in `src/components/design`. There is no
registry command to add it; the source is owned by this project.

```tsx
// src/components/design/code.tsx
// Source-owned composition. Edit directly in this repo.
```

## Usage

```tsx
import {
  CodeBlock,
  CodeBlockBody,
  CodeBlockContent,
  CodeBlockHeader,
  CodeBlockSource,
} from "@/components/design/code";
```

For the common case, render a complete (header-less) block from a raw string with
`CodeBlockSource`:

```tsx
<CodeBlockSource code={code} language="tsx" collapsible />
```

The header is a plain slot — compose whatever primitives you want inside it:

```tsx
import { Badge } from "@/components/ui/badge";
import { CopyButton } from "@/components/ui/copy-button";

<CodeBlock>
  <CodeBlockHeader>
    <Badge variant="secondary">TSX</Badge>
    <span className="text-xs text-muted-foreground">save-button.tsx</span>
    <CopyButton value={code} className="ml-auto" />
  </CodeBlockHeader>
  <CodeBlockBody>
    <CodeBlockContent code={code} language="tsx" />
  </CodeBlockBody>
</CodeBlock>;
```

## Composition

`CodeBlock` provides the expanded-state context that `CodeBlockBody` and
`CodeBlockExpandTrigger` read from. `CodeBlockHeader` is an unstyled slot — it has no
baked-in badge, path, or copy button; you compose those from existing primitives.

```text
CodeBlock
├── CodeBlockHeader        (optional — compose Badge / text / CopyButton)
└── CodeBlockBody
    ├── CodeBlockContent
    └── CodeBlockExpandTrigger (auto, when collapsible)
```
