## Installation

```bash
bunx shadcn@latest add avatar
```

## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar";
```

```tsx
<Avatar>
  <AvatarImage src="/avatar.png" alt="Manik Rana" />
  <AvatarFallback>MR</AvatarFallback>
</Avatar>
```

## API Reference

### Avatar

| Prop        | Type                                                          | Default     |
| ----------- | ------------------------------------------------------------- | ----------- |
| `size`      | `"3xs" \| "2xs" \| "xs" \| "sm" \| "default" \| "lg" \| "xl"` | `"default"` |
| `radius`    | `"rounded" \| "full"`                                         | `"full"`    |
| `className` | `string`                                                      | -           |

### AvatarImage

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `src`       | `string` | -       |
| `alt`       | `string` | -       |
| `className` | `string` | -       |

### AvatarFallback

| Prop        | Type              | Default |
| ----------- | ----------------- | ------- |
| `children`  | `React.ReactNode` | -       |
| `className` | `string`          | -       |

### AvatarBadge

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AvatarGroup

| Prop        | Type              | Default |
| ----------- | ----------------- | ------- |
| `children`  | `React.ReactNode` | -       |
| `className` | `string`          | -       |

### AvatarGroupCount

| Prop        | Type              | Default |
| ----------- | ----------------- | ------- |
| `children`  | `React.ReactNode` | -       |
| `className` | `string`          | -       |
