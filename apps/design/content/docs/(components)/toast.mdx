## Installation

```bash
bunx shadcn@latest add sonner
```

## Usage

Add the toaster once near the app root.

```tsx
import { Toaster } from "@/components/ui/sonner";
```

```tsx
<Toaster />
```

Trigger toasts with `toast` from `sonner`.

```tsx
import { toast } from "sonner";

toast("Component saved", {
  description: "The preview is ready.",
});
```

## API Reference

### Toaster

| Prop           | Type                            | Default        |
| -------------- | ------------------------------- | -------------- |
| `position`     | `ToasterProps["position"]`      | -              |
| `theme`        | `"light" \| "dark" \| "system"` | `"system"`     |
| `toastOptions` | `ToasterProps["toastOptions"]`  | Local defaults |

### toast

| API                               | Type                                                             |
| --------------------------------- | ---------------------------------------------------------------- |
| `toast(message, options)`         | `(message: string, options?: ExternalToast) => string \| number` |
| `toast.success(message, options)` | `(message: string, options?: ExternalToast) => string \| number` |
| `toast.warning(message, options)` | `(message: string, options?: ExternalToast) => string \| number` |
| `toast.error(message, options)`   | `(message: string, options?: ExternalToast) => string \| number` |
