## Installation

```bash
bunx shadcn@latest add sonner
```

## Usage

Add the toaster once near the app root.

```tsx
import { Toaster } from "@/components/ui/sonner";
```

```tsx
<Toaster />
```

Trigger toasts with `toast` from `sonner`.

```tsx
import { toast } from "sonner";

toast("Component saved", {
  description: "The preview is ready.",
});
```
