## Installation

```bash
bunx shadcn@latest add checkbox
```

## Usage

```tsx
import { Checkbox } from "@/components/ui/checkbox";
```

```tsx
<Checkbox defaultChecked />
```

## Composition

Pair `Checkbox` with `Field` and `FieldLabel` for layout and labeling.

```text
Field (orientation="horizontal")
├── Checkbox
└── FieldLabel  (or FieldContent → FieldLabel + FieldDescription)
```

## Accessibility

- Always associate a `FieldLabel` (via `htmlFor`/`id`) so the control is labeled.
- Use `aria-invalid` on the checkbox and `data-invalid` on the `Field` for the invalid state.
- Use `Space` to toggle the focused checkbox.

## API Reference

### Checkbox

Built on the Base UI `Checkbox.Root` primitive. Accepts all of its props plus `className`.

| Prop              | Type                         | Default |
| ----------------- | ---------------------------- | ------- |
| `checked`         | `boolean`                    | -       |
| `defaultChecked`  | `boolean`                    | `false` |
| `onCheckedChange` | `(checked: boolean) => void` | -       |
| `indeterminate`   | `boolean`                    | `false` |
| `disabled`        | `boolean`                    | `false` |
| `aria-invalid`    | `boolean`                    | -       |
| `className`       | `string`                     | -       |

The component exposes `data-slot="checkbox"` on the root, `data-slot="checkbox-box"` on the
visual, and `data-slot="checkbox-indicator"` on the check/minus icon for styling hooks.
