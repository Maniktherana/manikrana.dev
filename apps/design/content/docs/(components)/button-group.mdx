## Installation

```bash
bunx shadcn@latest add button-group
```

## Usage

```tsx
import { Button } from "@/components/ui/button";
import { ButtonGroup, ButtonGroupSeparator, ButtonGroupText } from "@/components/ui/button-group";
```

```tsx
<ButtonGroup variant="base">
  <Button>Button 1</Button>
  <Button>Button 2</Button>
</ButtonGroup>
```

## Composition

Use the following composition to build a `ButtonGroup`.

```text
ButtonGroup
├── Button or Input
├── ButtonGroupSeparator
├── ButtonGroupText
└── ButtonGroup
```

## Accessibility

- The `ButtonGroup` component has `role="group"`.
- Use `Tab` to navigate between controls in the group.
- Use `aria-label` or `aria-labelledby` to label the button group.

```tsx
<ButtonGroup aria-label="Button group">
  <Button>Button 1</Button>
  <Button>Button 2</Button>
</ButtonGroup>
```

## ButtonGroup vs ToggleGroup

- Use `ButtonGroup` when controls perform actions.
- Use `ToggleGroup` when controls toggle or select state.

## API Reference

### ButtonGroup

The `ButtonGroup` component is a container that groups related controls together with
consistent styling.

| Prop          | Type                               | Default        |
| ------------- | ---------------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"`       | `"horizontal"` |
| `variant`     | `"default" \| "base" \| "toolbar"` | `"default"`    |
| `size`        | `"default" \| "compact"`           | `"default"`    |
| `className`   | `string`                           | -              |

```tsx
<ButtonGroup variant="base" size="compact">
  <Button>Button 1</Button>
  <Button>Button 2</Button>
</ButtonGroup>
```

Use `variant="default"` when the group should use the component surface. Use `variant="base"`
when the group should sit on the page background. Use `variant="toolbar"` when the group
is only spacing multiple child `ButtonGroup` clusters.

Nested button groups also get toolbar spacing automatically, so simple nested composition works.

```tsx
<ButtonGroup variant="toolbar">
  <ButtonGroup variant="base" />
  <ButtonGroup variant="base" />
</ButtonGroup>
```

### ButtonGroupSeparator

The `ButtonGroupSeparator` component visually divides buttons within a group.

| Prop          | Type                         | Default      |
| ------------- | ---------------------------- | ------------ |
| `orientation` | `"horizontal" \| "vertical"` | `"vertical"` |
| `className`   | `string`                     | -            |

```tsx
<ButtonGroup>
  <Button>Button 1</Button>
  <ButtonGroupSeparator />
  <Button>Button 2</Button>
</ButtonGroup>
```

### ButtonGroupText

Use `ButtonGroupText` to display text within a button group.

| Prop        | Type           | Default |
| ----------- | -------------- | ------- |
| `render`    | `ReactElement` | -       |
| `className` | `string`       | -       |

```tsx
<ButtonGroup>
  <ButtonGroupText>Text</ButtonGroupText>
  <Button>Button</Button>
</ButtonGroup>
```

Use the `render` prop to render a custom component as the text, for example a label.

```tsx
import { ButtonGroup, ButtonGroupText } from "@/components/ui/button-group";
import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";

export function ButtonGroupTextDemo() {
  return (
    <ButtonGroup>
      <ButtonGroupText render={<Label htmlFor="name" />}>Text</ButtonGroupText>
      <Input placeholder="Type something here..." id="name" />
    </ButtonGroup>
  );
}
```
