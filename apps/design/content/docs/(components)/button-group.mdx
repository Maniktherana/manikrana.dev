## Installation

```bash
bunx shadcn@latest add button-group
```

## Usage

```tsx
import { Button } from "@/components/ui/button";
import { Group, GroupSeparator, GroupText } from "@/components/ui/group";
```

```tsx
<Group variant="base">
  <Button>Button 1</Button>
  <Button>Button 2</Button>
</Group>
```

## Composition

Use the following composition to build a `Group`.

```text
Group
├── Button or Input
├── GroupSeparator
├── GroupText
└── Group
```

## Accessibility

- The `Group` component has `role="group"`.
- Use `Tab` to navigate between controls in the group.
- Use `aria-label` or `aria-labelledby` to label the button group.

```tsx
<Group aria-label="Button group">
  <Button>Button 1</Button>
  <Button>Button 2</Button>
</Group>
```

## Group vs ToggleGroup

- Use `Group` when controls perform actions.
- Use `ToggleGroup` when controls toggle or select state.
