## Installation

```bash
bunx shadcn@latest add calendar
```

## Usage

```tsx
import { Calendar } from "@/components/ui/calendar";
```

```tsx
const [date, setDate] = React.useState<Date | undefined>(new Date());

return (
  <Calendar
    mode="single"
    selected={date}
    onSelect={setDate}
  />
);
```

## About

`Calendar` is built on top of `react-day-picker` and keeps the shadcn/Base UI
composition: a source-owned `Calendar` wrapper, a replaceable `CalendarDayButton`,
and DayPicker props passed through.

## Date Picker

There is no exported date picker component. Compose date pickers from `Calendar`
with `Popover`, `Button`, `InputGroup`, or other local primitives.

## API Reference

### Calendar

| Prop | Type | Default |
| --- | --- | --- |
| `mode` | `"single" \| "multiple" \| "range"` | - |
| `selected` | DayPicker selected value for the active mode | - |
| `onSelect` | DayPicker select handler for the active mode | - |
| `captionLayout` | `"label" \| "dropdown" \| "dropdown-months" \| "dropdown-years"` | `"label"` |
| `showOutsideDays` | `boolean` | `true` |
| `buttonVariant` | `Button["variant"]` | `"default"` |
| `timeZone` | `string` | - |
| `locale` | `Locale` | - |
| `classNames` | `Partial<ClassNames>` | - |
| `components` | `Partial<CustomComponents>` | - |

### CalendarDayButton

| Prop | Type | Default |
| --- | --- | --- |
| `day` | `DayPicker` day object | - |
| `modifiers` | `DayPicker` modifiers object | - |
| `locale` | `Partial<Locale>` | - |
| `className` | `string` | - |
