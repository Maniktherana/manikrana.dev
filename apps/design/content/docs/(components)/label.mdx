## Installation

```bash
bunx shadcn@latest add label
```

## Usage

```tsx
import { Label } from "@/components/ui/label";
```

```tsx
<Label htmlFor="email">Customer email</Label>
```

## Examples

### Input

Pair `Label` with a text input by matching `htmlFor` to the control `id`.

<ComponentPreview name="label-input" />

### Checkbox

Use labels with checkbox and radio controls so the text toggles the control.

### Label

| Prop        | Type              | Default |
