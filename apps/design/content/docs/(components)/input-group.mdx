## Installation

`InputGroup` is the primitive for inputs that need leading icons, trailing
actions, keyboard hints, helper text, or multiline addons inside one control
surface.

## Usage

```tsx
import { InputGroup, InputGroupAddon, InputGroupInput } from "@/components/ui/input-group";
```

```tsx
<InputGroup variant="component">
  <InputGroupAddon>
    <SearchIcon />
  </InputGroupAddon>
  <InputGroupInput placeholder="Search products" />
</InputGroup>
```

## API Reference

### Composition

| Primitive            | Purpose                                                                    |
| -------------------- | -------------------------------------------------------------------------- |
| `InputGroup`         | Owns the control surface, size, radius, variant, focus, and invalid state. |
| `InputGroupAddon`    | Holds icons, keyboard hints, text, or inline actions.                      |
| `InputGroupInput`    | Provides the actual input field.                                           |
| `InputGroupButton`   | Adds clear, submit, or filter actions inside the group.                    |
| `InputGroupTextarea` | Provides a multiline grouped control.                                      |

### InputGroup Props

| Prop        | Type                                  | Default     |
| ----------- | ------------------------------------- | ----------- |
| `variant`   | `"default" \| "component" \| "muted"` | `"default"` |
| `size`      | `"default" \| "sm"`                   | `"default"` |
| `radius`    | `"squared" \| "rounded"`              | `"squared"` |
| `className` | `string`                              | -           |
