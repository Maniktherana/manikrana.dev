## Installation

```bash
bunx shadcn@latest add kbd
```

## Usage

```tsx
import { Kbd, KbdGroup } from "@/components/ui/kbd";
```

Single key:

```tsx
<Kbd>K</Kbd>
```

Multiple keys:

```tsx
<KbdGroup>
  <Kbd>Cmd</Kbd>
  <Kbd>K</Kbd>
</KbdGroup>
```
