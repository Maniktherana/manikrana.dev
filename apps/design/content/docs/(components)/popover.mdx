## Installation

```bash
bunx shadcn@latest add popover
```

## Usage

```tsx
import {
  Popover,
  PopoverClose,
  PopoverContent,
  PopoverDescription,
  PopoverTitle,
  PopoverTrigger,
} from "@/components/ui/popover";
```

```tsx
<Popover>
  <PopoverTrigger render={<button type="button" />}>Open popover</PopoverTrigger>
  <PopoverContent>
    <PopoverTitle>Popover title</PopoverTitle>
    <PopoverDescription>Popover description.</PopoverDescription>
    <PopoverClose>Close</PopoverClose>
  </PopoverContent>
</Popover>
```

## API Reference

### Popover

Root component. Alias for `Popover.Root` from Base UI.

| Prop           | Type                      | Default |
| -------------- | ------------------------- | ------- |
| `open`         | `boolean`                 | -       |
| `defaultOpen`  | `boolean`                 | -       |
| `onOpenChange` | `(open: boolean) => void` | -       |

### PopoverTrigger

Trigger button that opens the popover. Alias for `Popover.Trigger` from Base UI.

| Prop        | Type                                             | Default |
| ----------- | ------------------------------------------------ | ------- |
| `render`    | `ReactElement \| (props, state) => ReactElement` | -       |
| `className` | `string`                                         | -       |

### PopoverContent

Popup container that displays the popover content. Also exported as `PopoverPopup`.

| Prop          | Type                                                                       | Default    |
| ------------- | -------------------------------------------------------------------------- | ---------- |
| `side`        | `"top" \| "right" \| "bottom" \| "left" \| "inline-start" \| "inline-end"` | `"bottom"` |
| `sideOffset`  | `number`                                                                   | `8`        |
| `align`       | `"start" \| "center" \| "end"`                                             | `"center"` |
| `alignOffset` | `number`                                                                   | `4`        |
| `portalProps` | `Popover.Portal.Props`                                                     | -          |
| `className`   | `string`                                                                   | -          |

### PopoverTitle

Title text for the popover. Styled wrapper for `Popover.Title` from Base UI.

### PopoverDescription

Description text for the popover. Styled wrapper for `Popover.Description` from Base UI.

### PopoverClose

Close button for the popover. Alias for `Popover.Close` from Base UI.
