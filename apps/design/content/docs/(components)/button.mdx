## Installation

```bash
bunx shadcn@latest add button
```

## Usage

```tsx
import { Button } from "@/components/ui/button";
```

```tsx
<Button variant="secondary">Button</Button>
```

## Cursor

Tailwind v4 switched from `cursor: pointer` to `cursor: default` for buttons.

If you want to keep the pointer cursor behavior, add the following code to your global CSS.

You can also enable this during project setup with `bunx shadcn@latest init --pointer`.

```css
@layer base {
  button:not(:disabled),
  [role="button"]:not(:disabled) {
    cursor: pointer;
  }
}
```

### As Link

Use `buttonVariants` with a plain `a` element when a link should look like a button.

Do not use `<Button render={<a />} nativeButton={false} />` for links. Base UI button behavior is for button semantics; use `buttonVariants` with a plain `a` instead.

## API Reference

### Button

The `Button` component is a wrapper around the `button` element that adds a variety of styles and functionality.

| Prop      | Type                                                                                 | Default     |
| --------- | ------------------------------------------------------------------------------------ | ----------- |
| `variant` | `"default" \| "secondary" \| "outline" \| "ghost" \| "destructive" \| "link"`        | `"default"` |
| `size`    | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` |
