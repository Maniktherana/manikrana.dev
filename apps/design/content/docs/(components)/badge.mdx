## Installation

```bash
bunx shadcn@latest add badge
```

## Usage

```tsx
import { Badge } from "@/components/ui/badge";
```

```tsx
<Badge variant="success">Badge</Badge>
```

## Composition

Import the primitive that matches the badge anatomy you need.

```tsx
import { SparklesIcon } from "lucide-react";

import { Avatar, AvatarFallback } from "@/components/ui/avatar";
import {
  Badge,
  IconBadge,
  StatusBadge,
  UserBadge,
} from "@/components/ui/badge";
```

```tsx
<Badge variant="information">Badge</Badge>
<StatusBadge status="success">Live</StatusBadge>
<IconBadge variant="feature" aria-label="Feature">
  <SparklesIcon />
</IconBadge>
<UserBadge>
  <Avatar size="2xs">
    <AvatarFallback className="bg-[#18181b] text-white">M</AvatarFallback>
  </Avatar>
  Manik
</UserBadge>
```

## API Reference

### Badge

The main `Badge` component maps to the Figma Badge set.

| Prop        | Type                                                                                           | Default     |
| ----------- | ---------------------------------------------------------------------------------------------- | ----------- |
| `variant`   | `"default" \| "neutral" \| "secondary" \| "information" \| "success" \| "warning" \| "destructive" \| "error" \| "feature" \| "alpha" \| "outline" \| "ghost" \| "link"` | `"default"` |
| `radius`    | `"rounded" \| "full"`                                                                          | `"rounded"` |
| `render`    | `ReactElement`                                                                                 | -           |
| `className` | `string`                                                                                       | -           |

### StatusBadge

`StatusBadge` uses the neutral badge surface with a colored indicator.

| Prop        | Type                                                                                           | Default     |
| ----------- | ---------------------------------------------------------------------------------------------- | ----------- |
| `status`    | `"neutral" \| "default" \| "secondary" \| "information" \| "success" \| "warning" \| "destructive" \| "error" \| "feature" \| "alpha"` | `"neutral"` |
| `indicator` | `"swatch" \| "dot"`                                                                            | `"swatch"`  |
| `className` | `string`                                                                                       | -           |

### IconBadge

`IconBadge` maps to the 20px Figma icon badge.

| Prop        | Type                                                                                           | Default     |
| ----------- | ---------------------------------------------------------------------------------------------- | ----------- |
| `variant`   | `"default" \| "neutral" \| "secondary" \| "information" \| "success" \| "warning" \| "destructive" \| "error" \| "feature" \| "alpha" \| "outline" \| "ghost" \| "link"` | `"default"` |
| `className` | `string`                                                                                       | -           |

### UserBadge

`UserBadge` is a composable avatar chip.

```tsx
<UserBadge>
  <Avatar size="2xs">
    <AvatarFallback className="bg-[#18181b] text-white">M</AvatarFallback>
  </Avatar>
  Manik
</UserBadge>
```
